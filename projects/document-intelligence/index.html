MISSION BRIEF

Enterprise Document Intelligence Platform

A local document question-answering prototype. Upload PDF, Markdown or text files, ask a question, and inspect the retrieved passages alongside an answer generated by a locally hosted language model.

WHAT I BUILT

I built the document workflow, hybrid retrieval pipeline, evidence display and evaluation tools. Qwen3 runs locally through Ollama; SentenceTransformers supplies embeddings and reranking.

NOTEPrototype scope: roles are selected in the interface; production identity and authentication are not implemented.

How it comes together

  1. 01Upload documents
  2. 02Retrieve & rerank

01

Hybrid retrieval

Combines semantic search and BM25 keyword retrieval, then uses a cross-encoder to rerank the evidence.

02

Visible evidence

Shows retrieved passages and their scores beside the generated answer so the source context stays clear.

03

Retrieval evaluation

Includes Hit@K and MRR evaluation plus tests for role filtering, text chunking and metric calculations.
